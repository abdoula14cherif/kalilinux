BIENTÔT

Python SDK

Bibliothèque Python pour intégrer facilement l'API Boost Reseller dans vos scripts et applications.

pip install boost-reseller
BIENTÔT

JavaScript SDK

Pour Node.js et applications front-end. Compatible avec TypeScript.

npm install boost-reseller
BIENTÔT

PHP SDK

Bibliothèque PHP moderne avec PSR-4, Composer et support Laravel/Symfony.

composer require boost-reseller/sdk

Aperçu d'utilisation (Python) 

from boost_reseller import Client

# Initialisation
client = Client(api_key="bsk_live_xxxx")

# Recuperer les produits
produits = client.produits.list(limit=20)
for p in produits:
    print(f"{p.nom} - {p.prix} FCFA")

# Creer un produit
nouveau = client.produits.create(
    nom="T-shirt Nike",
    prix=15000,
    stock=50,
    description="T-shirt coton bio"
)
print(f"Cree : {nouveau.id}")

# Recuperer les commandes en attente
commandes = client.commandes.list(statut="en_attente")

# Mettre a jour une commande
client.commandes.update("CMD-ABC123", statut="livree")

# Voir les stats
stats = client.stats.get(periode="30j")
print(f"Revenus : {stats.revenus} FCFA")
