Les webhooks vous permettent de recevoir une requête HTTP sur votre serveur à chaque événement (nouvelle commande, paiement reçu, etc.).

URL du webhook

Nous enverrons un POST à cette URL à chaque événement.

Événements disponibles

commande.creee
Déclenché quand un client passe une nouvelle commande
commande.confirmee
Déclenché quand vous confirmez une commande
commande.livree
Déclenché quand une commande est livrée
commande.annulee
Déclenché quand une commande est annulée
paiement.recu
Déclenché quand un paiement est validé
client.inscrit
Déclenché quand un nouveau client s'inscrit
avis.ajoute
Déclenché quand un client laisse un avis
produit.stock_bas
Déclenché quand un produit est presque épuisé

Configuration en cours de finalisation

La configuration des webhooks sera disponible très bientôt. En attendant, vous pouvez utiliser nos clés API pour interroger nos endpoints régulièrement.
